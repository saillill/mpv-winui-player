# v4.2 菜单宿主 实机验证清单

> 用途：验收 v4.1/v4.2（MenuFlyout 单进程 + 审查修正）。每项记录 ✅/❌ + 现象；
> 发现问题时附 host_log 日志与截图。按用户约束，动态测试由用户实机执行。

## 准备

- 重启 mpv（让新 dyn_menu.lua / dyn_menu.conf 生效；宿主 DLL 已部署，无预热）；
- 宿主日志已临时开启：`C:\Users\z2637\AppData\Local\Temp\mpv-menu-host.log`
  （验证完可删除 dyn_menu.conf 里的 host_log 行）；
- 如测图标自定义：在 `tools\winui-menu-host\` 放 `icon-map.json`
  （格式见宿主 README“外观与可配置性决策”）。

## 验证项

| # | 检查点 | 通过标准 |
|---|---|---|
| 1 | 右键呼出 | 菜单在光标处弹出，无白屏/白框/闪跳 |
| 2 | 顶部无标题 | 菜单顶部没有“mpv 菜单”等标题 |
| 3 | 图标 | 打开/播放/导航/视频/工具/关于等有图标；播放列表/轨道/配置文件等动态项也继承图标且列对齐，无豆腐块 |
| 4 | 二级菜单 | 悬停“视频/音频/工具/打开”等约 300ms 展开，方向正确（右缘向左/左缘向右） |
| 5 | 三级菜单 | 如 视频>调色>对比度 +1：级联展开、方向正确、无闪烁 |
| 6 | 深层菜单 | 任意 ≥4 层子菜单能完整显示（v4.2 递归解析，不再限 3 层） |
| 7 | 重叠与动画 | 子菜单与一级重叠、展开动画为平台原生（Win11 观感），无图层互盖 |
| 8 | 单进程 | 打开三级菜单后任务管理器仅 1 个 MpvMenuHost.exe（Flyout 为同进程弹层） |
| 9 | 叶子执行 | 点击任意层叶子项，mpv 执行对应命令且菜单整链关闭 |
| 10 | Esc/点外 | 任意层 Esc 或点菜单外区域，菜单关闭且可再次呼出 |
| 11 | 键盘导航 | ↑/↓ 移动高亮、Enter 选中；无焦点窗口也可用 |
| 12 | 播放列表/音轨按钮 | 按钮菜单从鼠标上方弹出，条目可点 |
| 13 | 动态菜单 | 轨道/章节/配置文件/着色器/最近播放/音频设备能生成正确条目 |
| 14 | 深浅色 | 系统切换深浅色时菜单跟随（强制 --theme 时除外） |
| 15 | 反复呼出 | 连续 10 次右键→关闭：不卡死、无残留进程、%TEMP% 无新增 mpv-menu-host-* |
| 16 | 回退 | 临时改名 tools\winui-menu-host 后右键回退 menu.dll 原生菜单，mpv 不崩 |
| 17 | 图标自定义（可选） | 放置 icon-map.json 后对应标题图标被覆盖；删除后恢复内置 |
| 18 | 查看子菜单 | 右键→查看：展开不卡死（快捷键仅显示不注册，#708 规避） |

## 回报格式

- 失败项：#编号 + 现象（如“5：三级菜单展开后向左，且边缘闪烁”）；
- 有日志：附 host_log 相关行（FLYOUT shown / EXEC / ERR）；
- 有截图：贴菜单外观。

## 预期基线（v4.1/v4.2）

- 外观全平台默认（无 300px 硬编码、无自定义动画参数）；行尾快捷键显示原文
  （含 Alt+-、·、TAB、Del）；
- 图标：157 精确 + 47 前缀 + 用户 icon-map.json 覆盖 + 动态项继承；
- 宿主窗口 1×1 透明置顶（alpha=0 + 空区域），不可见；菜单为 MenuFlyout 平台弹层。
