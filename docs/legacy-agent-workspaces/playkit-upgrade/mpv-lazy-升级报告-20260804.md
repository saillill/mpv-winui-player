- **HDR**：保留 `vo=gpu-next` + `target-colorspace-hint=yes` + `HDR_generic` 自动映射配置。
- **Win11 风格音量浮窗**：新增 `scripts/volume_win11.lua`（竖向圆角浮窗：图标 + 百分比 + 滑条，约 1.2 秒自动隐藏），并将音量/静音绑定改为 `no-osd`，不再显示 mpv 原生音量条。
- **竖屏适配**：`[portrait_ui]` 保留，竖屏窗口下 ModernX 缩放自动降为 1.0。
- **保留的自定义内容**：`input.conf`、`mpv.conf`、`profiles.conf`、`script-opts.conf`、右键菜单（menu.dll 等）、NV 着色器（NVScaler/NVSharpen）、RIFE v4.6 常用模型、补帧 2x/3x/4x 脚本、播放进度（watch_later）、封面/元数据/最近播放脚本。

## 后续调整（同日补充）

- **VSR 触发规则**：改为“视频分辨率低于 4K 自动开启 NVIDIA VSR 2x”（不再依赖窗口大小），与 PotPlayer 的行为一致。已实测：1080p 自动挂载 `@vsr`，4K 不挂载。如需调整倍率，修改 `profiles.conf` 中 `[vsr_auto]` 的 `scale=` 值。
- **VSR / HDR 状态角标**：曾自行添加角标脚本，后按用户说明移除——NVIDIA 驱动会在 VSR/HDR 生效时自动显示标记，无需额外实现。
- **音量浮窗修复**：之前浮窗不显示是因为被 ModernX 的 OSD 层覆盖；现在音量浮窗与角标都使用高层级 OSD（z=100），滚轮/按键调音量时应能正常弹出。
- **音量浮窗二次修复**：改为绝对坐标绘制并移至画面底部（`bottom_offset=220`），背景更不透明、文字放在浮窗内部，避免之前部件位置错乱的问题。
- **音量浮窗最终决定**：按用户要求恢复 mpv 原生音量条（删除自定义浮窗脚本，音量/静音绑定恢复为 `add volume` / `cycle mute`）。
- **右键菜单恢复**：`menu.conf`（mpv 0.41 原生中文菜单）此前被误删，现已恢复并清理了指向不存在着色器的条目；右键菜单统一为中文原生菜单。
- **右键菜单最终决定**：按用户要求恢复 mpv-menu-plugin 自定义菜单——新增 `script-opts/dyn_menu.conf` 设置 `use_mpv_impl=no`，并移除 `menu.conf`，右键菜单重新由 menu.dll 渲染用户自定义的中文菜单（含 Nvidia VSR / RIFE / K7s / NV 滤镜等项）。
- **菜单合并**：将原生菜单（menu.conf）的独有选项合并进自定义菜单——新增 播放 > 重置音频与字幕同步、视频 > 切换解码模式/自动校色/时间码解析模式、工具 > 按键绑定列表/常驻统计/OSD命令行/清除属性/按键名检测/select 菜单/音频输出设备、VF 滤镜预设（MVTools/RIFE/DRBA/UAI 的 DX12 与 RTX 版）、截屏（无OSD/窗口/原始）、关于（项目主页/mpv手册/中文手册/FAQ/滤镜指北/着色器指南）。绑定数 188 → 225。
