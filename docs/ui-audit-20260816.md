# mpv-winui-player 前端界面审计（动画/刷新/模块度/统一度/原生度）

## 摘要

- 对象：当前 HEAD `d61113a` 的 WinUI 3 前端层（Player / PiP / Settings / 公共控件）。
- 方法：纯静态审计（源码、XAML、`check-localization.py --xaml-audit`、`check-settings-drift.py`），不启动应用。
- 交付：本报告 + 同轮代码修复；最终实机验证由用户完成（见文末实测清单）。
- 结论概览：动画机制多样但均有文档化理由，已做常量/死代码统一；刷新链路事件化程度高，主要去重了菜单栏二次本地化；模块度靠 partial 拆分已进一步收敛（快捷面板、PiP）；统一度主要补了共享样式与图标常量；原生度主要补了运行期文案与无障碍命名。

## 分轴发现

### 1. 动画实现

- 面板显隐有三条路径：窗口模式用 XAML Storyboard（180/150ms + CubicEase EaseOut）；overlay/全屏用同一 Storyboard 机制；PiP 用 Composition 透明度动画 + 16ms DispatcherTimer 驱动 XAML TranslateTransform（AGENTS.md 已记录 Storyboard 在第二个顶层窗口崩溃、Composition Offset 由布局拥有不可动画）。PiP 顶钮用 Composition ScalarKeyFrame + ScopedBatch。
- 问题：时长魔法数字 180/150 在 `PlayerControl.xaml.cs` 与 `Animation.cs` 重复；`PlayerControl_Loaded` 残留 6 行被注释的初始化调用。
- 修复：新增 `PanelShowMs=180`、`PanelHideMs=150` 共享常量并替换全部面板动画时长；overlay 双向保持 180ms（与旧行为一致）；删除死代码。
- 备注：XAML 中还有一条针对进度条/命令栏 Opacity 的 VisualState Storyboard、设置页控制条画布的 `RepositionThemeTransition`，均属合理原生用法；未改动。
- 一致性观察：主窗口与快捷面板各有一套 Equalizer UI（`PlayerControl.Flyouts.cs` 与快捷面板音频页），共享同一 `_eqGains`/`ApplyEqualizer`，属已知重复，建议后续合并为单一入口。

### 2. 刷新逻辑

- 已优化路径：进度 = 原生 `time-pos` 观察 + 100ms 合并；播放列表 = 事件合并 + id diff；预览 = 40ms 节流 + 单飞解码；显示信息 = 事件驱动 + 15s 兜底；快捷面板语言切换时仅重建内容（面板开着才重建）。
- 问题：`MpvPlayerPage.ApplyLocalizedStrings` 对 MenuBar 做了二次赋值（`MenuBarBuilder.Build` 已用 AppLang 生成标签）；运行期仍有英文：倍速 “Custom…”、Equalizer 按钮/标题、延迟面板标题与两个滑块标签、A-B loop ToolTip、自定义倍速对话框 “OK”。
- 修复：删除菜单栏重复循环；上述文案全部改走 `AppLang`（新增 `ControlBarIconAbLoop`、`PanelDelay` 两个键 ×8 语言）；为延迟/均衡器控件补 `AutomationProperties.Name`；自定义倍速对话框按钮用 `AppLang.Ok`。
- 备注：菜单栏整树重建、设置页选项树重建、历史/稍后观看列表 Clear+Add 均属低频路径（语言切换/打开对话框），本轮不改。

### 3. 模块度

- 现状：`PlayerControl` 已按 Animation/ControlPanel/Flyouts 拆分；`MpvPlayerPage` 拆为 15 个 partial；`SettingsPage.Options.*` 按分类拆分。仍偏大的文件：`SettingsPage.Actions.cs`（1164 行）、`ControlBarCanvasControl.xaml.cs`（895 行）、`PiPWindow.xaml.cs`（拆分前 1023 行）。
- 修复：快捷面板构建器（音频/视频/字幕 + 共享控件工厂）从 `PlayerControl.ControlPanel.cs` 迁入 `QuickControlPanel` 的 4 个 partial（Builders/Audio/Video/Subtitles），`PlayerControl` 只保留 Pivot 外壳与宿主接线；`PiPWindow.xaml.cs` 拆为 `PiPWindow.cs`（生命周期/显示/本地化）、`PiPWindow.Resize.cs`（Win32 子类/尺寸/拖动/圆角）、`PiPWindow.Overlay.cs`（顶钮动画/遮罩/媒体事件）。
- 后续建议（本轮不做）：`SettingsPage.Actions.cs` 建议边界 = Shortcuts / Devices / Associations+Profiles / ControlBar / Config；`ControlBarCanvasControl` 建议按“模型（顺序/分区/隐藏）与视图（画布渲染/拖放）”拆分。

### 4. 统一度

- 现状：`Styles/Styles.xaml` 只有 2 个主题画刷；Player+Settings XAML 含 267 处内联 Width/Height/Margin/Padding/CornerRadius/FontSize；图标字体在 XAML 混用 Segoe 与 FluentSystemIcons（部分有 AGENTS 约定），代码内 FontFamily URI 字符串重复。
- 修复：新增 `MpvCardStyle`、`MpvSectionHeaderStyle`、`MpvCaptionTextStyle`（均走 ThemeResource）；快捷面板卡片与标签改用它；新增 `IconFonts` 常量类并替换 `MenuBarBuilder`、`ControlBarIconCatalog`、`IconMap`、快捷面板的 FontFamily 字符串。
- 备注：其余硬编码尺寸不改（收益低、回归风险大）；XAML 中的字体 URI 保留字面量（XAML 不易引用 C# 常量），代码侧统一即可。

### 5. 原生度

- 符合 WinUI 3 惯例的部分：NavigationView/MenuBar/CommandBar/Flyout/Pivot/ListView 等原生控件；XAML optional changes 已启用；主题资源/深浅色词典；AutomationProperties 覆盖面较好。
- 缺口与修复：unpackaged 无 x:Uid，XAML 英文默认值作为 fallback、运行时代码补本地化——本轮补齐 Equalizer/Delay/倍速/AB 循环等剩余运行期英文；补滑块/按钮无障碍名；修正 `RebuildMenuBar` 过期注释。
- 刻意保留：PiP 窗口标题固定英文 “Picture in picture”（AGENTS/UIA 冒烟依赖）；Win32 子类、键盘钩子、无边框 PiP 属嵌入播放器的必要妥协（AGENTS.md 已记录）。
