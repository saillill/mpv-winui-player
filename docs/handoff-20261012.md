## 六、容易踩的坑（都实际发生过）

| 现象 | 原因 | 处理 |
|------|------|------|
| 动画「缺失」，只看到淡入 | 位移距离只有 8px，肉眼读不到 | 距离加大到 24–48px |
| 只有第一个元素有动画，其余先实心闪现 | `StopAnimation(Opacity)` 恢复成 XAML 默认的 1，而带 `DelayTime` 的动画在延迟期不写属性 | 停放阶段显式 `visual.Opacity = 0f` |
| 淡入与位移差一帧 | 两个动画落在不同合成器 tick | `CreateScopedBatch` 圈成一批 |
| 滚动列表时动画反复重播 | 用了 `ContainerContentChanging`，容器复用时会再触发 | 一次性标志 + `LayoutUpdated` |
| 元素永久停在偏移位置 | 用了 `Visual.Offset`（布局拥有，动画结束仍持续填充） | 改走 `"Translation"` 属性集 |
| 编译报 `IsEnabled` 不存在 | 它在 `Control` 上，不在 `FrameworkElement` 上 | 逐类型设置 |
| `Double` 资源填不进 `Padding`/`Margin` | 它们是 `Thickness`，XAML 不做隐式转换 | 单独定义 `Thickness` 资源 |
| `<Thickness x:Key="A">{StaticResource B}</Thickness>` 编译失败 | 结构体类型资源的值不能写标记扩展 | 用 `<StaticResource x:Key="A" ResourceKey="B"/>` 别名写法 |
| XAML 报「标签不匹配」但行号指向别处 | 编辑时 `old_string` 没覆盖到闭合标签，导致重复了一个闭合标签 | XAML 编辑一定要包含闭合标签 |
| AppBarButton 设 `Background`/`BorderBrush` 无效 | 它的模板用主题画刷自绘 | 覆写 `AppBarButtonBackground` 等主题画刷资源 |

## 七、关键约定（代码层面）

- 播放页在 `ShellFrame` 里**永远只有 `MpvPlayerPage` 一个页面**：
  libmpv 对 `AttachSwapChain` 是一次性绑定，导航离开会卸载 `PlayerView`。
  导航项只驱动页面内部的筛选，不做 Frame 导航。
- 媒体库面板切换**从不碰视频**：`PlayerView` 始终 Visible 在树上，变的只是上面盖了什么。
- 状态栏按钮**必须保持 `AppBarButton`**：布局引擎按 `ICommandBarElement` 在三套 CommandBar
  之间搬运它们，换成普通 `Button` 会被踢出那套机制。
- 设置页行模板改动集中在 `OptionListControl.xaml` 一个文件（11 个 `DataTemplate`）。
- 图标：字体图标用 `IconFonts.FluentSystemIconsUri`；需要从数据驱动的地方用
  `FluentIcons.Geometry(...)` + `PathIcon`。
